Handoff: iOS Share Extension — Direct Reel Import (Memo Trip)
=============================================================

Copy this file into a new Cursor chat on your Mac to continue this work.

-----------------------------------------------------------------------------
FEATURE GOAL
-----------------------------------------------------------------------------

When a user shares an Instagram/TikTok/Facebook reel from the iOS share sheet
to Memo Trip:

1. The share extension POSTs the URL to Supabase import-video-job using the
   user's JWT.
2. Show alert: "The reel is being imported."
3. User taps OK and stays in Instagram (main app does not open).
4. Job runs server-side; when user opens Memo Trip later, the job appears on
   the Import tab.

Fallback path: If direct import fails (no token, network error, etc.),
extension can still deep-link into the app; ShareIntentHandler enqueues the URL
unless a direct-import handoff was consumed.

Cannot test in Expo Go — requires a dev build with native share extension +
App Groups.

-----------------------------------------------------------------------------
ARCHITECTURE (HIGH LEVEL)
-----------------------------------------------------------------------------

Instagram Share Sheet
  -> iOS Share Extension (ShareViewController.swift)
      -> reads JWT from App Group UserDefaults (key: memoTripSupabaseAccessToken)
      -> POST { url } to SUPABASE_URL/functions/v1/import-video-job
      -> alert + dismiss (no app open on success)

Main app (on sign-in)
  -> AuthContext calls setShareExtensionAccessToken(access_token)
  -> memo-share-extension-auth native module writes same App Group key

Main app (on cold start / share fallback)
  -> ShareIntentHandler: consumeDirectImportHandoff() — if URL present, skip
     navigate/enqueue
  -> ImportQueueContext polls/refreshes video_import_jobs from Supabase

App Group ID (hardcoded in native + template): group.com.tentzer.memotrip
Bundle ID: com.tentzer.memotrip
Scheme: memo-trip

-----------------------------------------------------------------------------
AUTH MECHANISM (CRITICAL)
-----------------------------------------------------------------------------

- JWT is NOT stored in Supabase for the extension.
- It lives in iOS App Group UserDefaults(suiteName: "group.com.tentzer.memotrip"),
  key: memoTripSupabaseAccessToken.
- Main app writes via native MemoShareExtensionAuth.setAccessToken.
- Share extension reads the same key in Swift (shareExtensionAuthKey).

Dev-only UI: On Import tab (video-import.tsx), in __DEV__ + iOS, banner shows:
  - "Share extension auth: ready" — token in App Group
  - "Share extension auth: missing — sign in once" — token not readable

Important: App sign-in (Supabase session) != share extension auth. The banner
checks App Group only. setShareExtensionAccessToken silently no-ops if:

1. Native module MemoShareExtensionAuth not linked in Xcode build, or
2. Main app target lacks App Groups entitlement for group.com.tentzer.memotrip, or
3. Build predates hasAccessToken in native module (banner always false).

-----------------------------------------------------------------------------
MAC BUILD STEPS (REQUIRED)
-----------------------------------------------------------------------------

  npm install
  npx expo prebuild --clean
  cd ios && pod install

Open ios/MemoTrip.xcworkspace (not .xcodeproj).

Ensure .env / .env.local has:
  EXPO_PUBLIC_SUPABASE_URL
  EXPO_PUBLIC_SUPABASE_ANON_KEY

Build to physical iPhone from Xcode (or npx expo run:ios).

Xcode checks:
  - Main app target -> Signing & Capabilities -> App Groups ->
    group.com.tentzer.memotrip (checked)
  - Share Extension target -> same App Group
  - After code changes: Clean Build, delete app from device, reinstall,
    sign in again

withShareExtensionDirectImport needs EXPO_PUBLIC_SUPABASE_URL (and anon key)
AT PREBUILD TIME so the Swift template gets the correct import-video-job
endpoint baked in.

-----------------------------------------------------------------------------
FAILURE SIGNALS
-----------------------------------------------------------------------------

Symptom: Banner "missing" after sign-in
  Likely: Native module not linked, App Groups missing on main app, stale ios/

Symptom: Extension "Sign in required"
  Likely: Same — JWT never written to App Group

Symptom: App opens to map/import
  Likely: Extension fell back to deep link; direct import failed

Symptom: Alert OK but no job
  Likely: Edge function error; check Supabase logs for import-video-job
          (401 = expired JWT -> re-sign in)

Symptom: withShareExtensionDirectImport warning in prebuild
  Likely: Run prebuild with expo-share-intent first so ios/ShareExtension/ exists
